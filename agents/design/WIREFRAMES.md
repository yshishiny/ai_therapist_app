# Design Agent - Wireframe Specs

## 1. Patient List Screen

- **Elements**: Search bar, filter (Active/Discharged), patient cards (Name, Last Session, Risk Level dot).
- **Actions**: Tap card to view profile, FAB for "Add Patient".

## 2. Patient Profile Screen

- **Tabs**: Overview, Notes, Assessments, Care Plan.
- **Overview**: Demographics, Risk Flags, Recent Symptoms chart.

## 3. Session Editor

- **Elements**: Selection for template (SOAP/DAP), text fields, "Draft AI Summary" button.
- **Actions**: Save, Finalize (locks note).

## 4. Assessment Dashboard

- **Elements**: List of active tests, completion status, score history graph.
