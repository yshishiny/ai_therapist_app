# Design Agent - Style Guide

## Color Palette (Calm & Clinical)

- **Primary (Sage)**: `#8FB9A8` - Used for primary buttons and success states.
- **Secondary (Slate)**: `#727077` - Used for secondary text and icons.
- **Accent (Sand)**: `#F1D3B3` - Used for background highlights.
- **Background (Cloud)**: `#F5F7F8` - Main screen background.
- **Risk (Coral)**: `#E6BA95` - Subdued red for risk alerts.

## Typography

- **Headings**: `Outfit` (Bold) - Clean, approachable.
- **Body**: `Inter` (Regular) - High readability for notes.

## Components

- **Cards**: Soft corners (`borderRadius: 16`), subtle elevation.
- **Buttons**: Large touch targets, haptic feedback on press.
- **Charts**: Minimalist lines, no cluttered axes.
