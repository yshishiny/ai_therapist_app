# Clinical Agent - User Stories

## Intake Flow

- **As a therapist**, I want to capture a patient's demographics and emergency contact so that I have a complete profile.
- **As a patient**, I want to provide my therapeutic history and goals so that the therapist understands my context.

## Session Flow

- **As a therapist**, I want to record session notes after each meeting so that I can track progress over time.
- **As a therapist**, I want the AI to draft a summary of the session note so that I can save time on documentation.

## Assessment Flow

- **As a therapist**, I want to assign standardized tests (PHQ-9/GAD-7) to patients so that I can measure symptom severity objectively.
- **As a patient**, I want to receive a reminder to complete my assigned assessments before the next session.

## Care Plan Flow

- **As a therapist**, I want to generate a phased care plan based on the patient's goals and symptoms so that we have a clear roadmap for recovery.
