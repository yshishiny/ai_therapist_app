# Sprint Roadmap

## Sprint 0 - Setup and governance
- Create docs backbone
- Confirm repository strategy
- Define branch and release flow
- Define environments: dev, staging, prod
- Seed milestones, labels, and initial epic issues
- Create Asana delivery board and align with GitHub

## Sprint 1 - Access foundation
- Add permissions and overrides
- Add clinician groups
- Add patient-clinician assignments
- Add audit logging for admin changes
- Add Practice Admin shell in Flutter

## Sprint 2 - Assessment admin v2
- Add assessment catalog and versioning
- Add question-bank bulk upload
- Add branch rules and publish flow
- Add clinician assessment entitlements
- Replace the old assessment admin tab

## Sprint 3 - Content, billing, and governance
- Add content items, versions, and IP policies
- Add secure content delivery and entitlement checks
- Add subscription plans, usage events, and invoice summaries
- Add audit viewer and governance screens
- Expand backend and frontend test coverage

## Sprint 4+
- Platform admin console
- Advanced analytics
- White-labeling
- Additional monetization packs and enterprise controls
