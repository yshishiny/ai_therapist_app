# AI Therapist Platform Docs

This folder is the planning and delivery backbone for the AI Therapist platform extension.

## Documents
- `product-vision.md` — product direction and scope
- `target-architecture.md` — target system architecture
- `domain-model.md` — core entities and relationships
- `api-roadmap.md` — planned backend/API evolution
- `db-migration-plan.md` — migration sequencing and schema rollout
- `sprint-roadmap.md` — phased delivery plan
- `delivery-governance.md` — operating model, environments, release flow, and controls

## Delivery principle
This work extends the existing application into a multi-tenant therapist SaaS platform with:
- practice administration
- policy-based access control
- versioned assessments
- protected content/IP controls
- patient-clinician assignment
- subscription and usage billing
- audit and compliance foundations
