# ACT Psychological Flexibility + Values Check-in (Original)

## What this is
Original training instrument for generating therapist-facing summaries.

## Subscales
- **Fusion/Avoidance**: items [1, 2, 3, 8, 10]
- **Mindful contact**: items [4, 9, 11]
- **Acceptance/Values/Action**: items [5, 6, 7, 12]

## Recommendation rules
If fusion high → defusion exercises. If avoidance high → acceptance + willingness ladder. If values clarity low → values exploration; if action low → committed action plan.

## Output contract
- Subscale totals + severity bands
- Risk flags (always)
- Non-diagnostic interpretation
- Suggested next-step questions + interventions aligned to the school
