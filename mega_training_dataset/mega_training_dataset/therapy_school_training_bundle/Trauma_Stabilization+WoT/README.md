# Trauma-Informed Stabilization & Window of Tolerance Screen (Original)

## What this is
Original training instrument for generating therapist-facing summaries.

## Subscales
- **Activation**: items [1, 2, 3, 4, 5, 6]
- **Resources**: items [7, 8, 9, 10, 11]
- **Risk markers**: items [12, 13]
- **Readiness preference**: items [14]

## Recommendation rules
If dissociation/panic high → prioritize external grounding, titration, eyes-open. If resources low → build stabilization plan. If risk markers high → immediate safety escalation.

## Output contract
- Subscale totals + severity bands
- Risk flags (always)
- Non-diagnostic interpretation
- Suggested next-step questions + interventions aligned to the school
