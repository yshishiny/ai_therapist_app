# DBT Diary Card + Risk/Skills Tracker (Original)

## What this is
Original training instrument for generating therapist-facing summaries.

## Subscales
- **Primary urges**: items [1, 2, 3]
- **Emotion intensity**: items [4, 5, 6, 7]
- **Interpersonal**: items [8]
- **Skills use**: items [9, 10, 11, 12, 13, 14]
- **Incidents**: items [15, 16]

## Recommendation rules
DBT hierarchy: Life-threatening (self-harm/violence) → Therapy-interfering → QoL. If high urges + low skills use → teach 1–2 skills (STOP, TIPP) + chain analysis.

## Output contract
- Subscale totals + severity bands
- Risk flags (always)
- Non-diagnostic interpretation
- Suggested next-step questions + interventions aligned to the school
