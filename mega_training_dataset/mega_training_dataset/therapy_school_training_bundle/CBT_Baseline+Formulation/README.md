# CBT Baseline + Formulation Mini-Intake (Original)

## What this is
Original training instrument for generating therapist-facing summaries.

## Subscales
- **Depressed mood/Anhedonia**: items [1, 2, 6]
- **Sleep/Energy/Appetite**: items [3, 4, 5]
- **Concentration**: items [7]
- **Anxiety/Worry**: items [8, 9, 10]
- **Avoidance/Safety behaviors**: items [11, 12, 14]
- **Rumination/Cognitive reactivity**: items [13, 15]
- **Stress load**: items [16]

## Recommendation rules
If avoidance/safety high → exposure ladder + reduce safety behaviors. If depression cluster high → behavioral activation. If rumination high → CBT/MBCT-style decentering + worry time.

## Output contract
- Subscale totals + severity bands
- Risk flags (always)
- Non-diagnostic interpretation
- Suggested next-step questions + interventions aligned to the school
