# Mega Therapy Agent Training Dataset

This mega-pack combines:
- SCID-II screening pack (Arabic DSM-IV) with fictional response sets + reports + JSON
- Therapy schools bundle (CBT/DBT/ACT/Trauma-informed) original instruments + 5 fictional cases each
- Extended support bundle (Psychodynamic + Couples/Systems) original instruments + therapist support templates/handouts
- Master intake bundle (multi-school, safety-first) with 8 fictional intakes + routing rules

All content is training/demo only; not diagnostic. Risk endorsements require clinician escalation.
