# Couples/Family Interaction Cycle & Safety Screen (Original)

## Subscales
- **Negative cycle intensity**: items [1, 3, 8, 9, 10]
- **Relationship safety/violence risk**: items [11]
- **Strengths/repair**: items [2, 4, 5]
- **Roles/structure**: items [6, 7]
- **Substance impact**: items [12]

## Rules
If intimidation/fear endorsed → prioritize safety assessment and appropriate referral. If negative cycle high → map cycle + teach time-outs/repair. If strengths low → build friendship/positive interactions first.

## Output contract
- Subscale totals + bands
- Safety/risk flags
- Non-diagnostic interpretation
- School-aligned next steps
