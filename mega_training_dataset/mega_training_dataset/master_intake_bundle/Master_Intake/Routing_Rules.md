# Routing rules (simple, training-ready)

Use composite patterns to suggest a *starting* approach:
- If Risk_Index elevated → safety planning first; consider DBT skills focus.
- If Trauma_Activation high and dissociation high → trauma-informed stabilization first.
- If Mood_Anhedonia + Functioning_Impact high → CBT behavioral activation.
- If Anxiety_Panic + Avoidance high (item 21/17/18) → CBT exposure + skills.
- If OCD_Rumination high → CBT/ERP or ACT defusion emphasis.
- If strengths high but values/action low (item 43 low; item 45 high) → ACT values + committed action.
- If relationship safety issue (item 39 high) → safety + systems/IPV referral considerations.

Always use non-diagnostic language and confirm via interview.
