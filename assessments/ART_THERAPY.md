# AI Therapist — Art Therapy Assessments

## Structured & Scorable Instruments

### 1. FEATS (Formal Elements Art Therapy Scale)

**Purpose**: Quantitative rating of formal elements in artwork  
**Best for**: Baseline, progress tracking, treatment outcomes

| Element             | Scale | Description                |
| ------------------- | ----- | -------------------------- |
| Prominence of color | 1-5   | Use and intensity of color |
| Color fit           | 1-5   | Appropriateness to content |
| Implied energy      | 1-5   | Movement/dynamism          |
| Space               | 1-5   | Use of page space          |
| Integration         | 1-5   | Cohesion of elements       |
| Logic               | 1-5   | Realistic vs abstract      |
| Realism             | 1-5   | Representational accuracy  |
| Problem-solving     | 1-5   | Creative solutions         |
| Developmental level | 1-5   | Age-appropriate skills     |
| Details             | 1-5   | Elaboration                |
| Line quality        | 1-5   | Control and expression     |
| Person              | 1-5   | Human figure quality       |
| Rotation            | 1-5   | Orientation issues         |
| Perseveration       | 1-5   | Repetitive patterns        |

**Training**: Requires FEATS training for reliable scoring

---

### 2. PPAT (Person Picking an Apple from a Tree)

**Purpose**: Standardized drawing directive for FEATS scoring  
**Best for**: Intake baseline, periodic monitoring

**Directive**: "Draw a person picking an apple from a tree"

**Materials**: 12x18 paper, 12 Mr. Sketch markers

**Scoring**: Use FEATS 14-element scale

**Norms**: Research correlates with depression, thought disorders

---

### 3. DDS (Diagnostic Drawing Series)

**Purpose**: Three-drawing assessment battery  
**Best for**: Comprehensive art-based evaluation

**Three drawings**:

1. **Free drawing** (unstructured)
2. **Tree drawing** (structured)
3. **Feeling drawing** (prompted)

**Scoring**: Trained raters use DDS rating guide

**Research**: Correlated with DSM diagnostic categories

## Projective Tools (Qualitative Use Only)

> ⚠️ **Warning**: These are useful for clinical exploration but should NOT be used for automated "diagnostic" scoring. Research validity for diagnosis is limited.

### HTP (House-Tree-Person)

- **Use**: Qualitative exploration of self-concept, family, environment
- **Do NOT**: Auto-score or present as diagnostic

### DAP (Draw-A-Person)

- **Use**: Developmental screening, rapport building
- **Do NOT**: Use for personality diagnosis

### KFD (Kinetic Family Drawing)

- **Use**: Family dynamics exploration
- **Do NOT**: Auto-interpret without clinical context

## Dashboard Integration

### Track over time:

- FEATS total score (sum of 14 elements)
- Individual element trends
- Qualitative therapist notes
- Photo/scan of artwork (with consent)

### Alerts:

- Significant drop in integration/logic scores
- Perseveration increase
- Color use changes (may indicate mood shifts)

---

## Session Workflow

```
1. Provide standardized materials
2. Give directive (PPAT or DDS sequence)
3. Client creates artwork (10-20 min)
4. Therapist scores using FEATS (post-session)
5. Results stored + trends displayed
6. Discuss artwork in next session (if appropriate)
```

| DDS         | DDS workshop/manual             |
